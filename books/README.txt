============================================================
DSA GRINDER :: BOOKS & RESOURCE ARCHIVE DIRECTORY
============================================================

Place your technical books, cheat sheets, papers, or manuals in this folder.
Supported Format: PDF only (.pdf)

AUTOMATIC CATALOG DISCOVERY:
1. Drop your PDF files into this "books" directory.
2. Launch DSA Grinder using "run_tracker.bat" or run "scan_books.bat".
3. Open the "BOOKS & DOWNLOADS" tab in DSA Grinder.
4. Only existing PDF books in this folder will be cataloged and displayed
   with 1-click download/open, file sizes, and reading status tracking.
   Deleted books are automatically removed when rescanning.
